An AI-powered research assistant that automates web research using a multi-agent workflow. It searches the web, extracts relevant information, generates structured reports, and critiques the final output to improve quality.

✨ Features
🤖 Multi-agent research pipeline (Search → Reader → Writer → Critic)
🌐 Real-time web search powered by Tavily API
🧠 High-quality report generation using Mistral AI
⚡ Streaming responses with FastAPI for live progress updates
🎨 Modern React frontend with an interactive research dashboard

🛠️ Tech Stack
Frontend: React, Vite
Backend: FastAPI, Python
AI: Mistral AI, LangChain
Search: Tavily API
